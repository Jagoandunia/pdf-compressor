# Windows PDF 压缩工具设计

## 目标

交付一个独立的 Windows 桌面程序。用户选择一个本地 PDF，选择压缩等级 1、2 或 3，程序生成一个新的压缩后 PDF，不改写原文件。

## 范围与验收标准

1. 用户可通过文件选择器选择一个本地 `.pdf` 文件。
2. 用户可选择 1、2、3 三档压缩等级，默认 2 级。
3. 点击“开始压缩”后，程序在与原文件相同的目录创建新文件，命名为 `<原文件名>_压缩_L<等级>.pdf`；如重名，自动追加序号。
4. 程序显示源文件体积、输出文件体积、压缩比例和输出文件位置。
5. 无效文件、加密/损坏 PDF、压缩引擎缺失、引擎失败、无磁盘空间和目标文件未生成时给出中文错误，不误报成功。
6. 成功后的输出文件可以被 PDF 引擎再次打开，且文件内容不是空文件。
7. 最终交付包含可在 64 位 Windows 上直接运行的 `PDF压缩工具.exe` 及其运行所需目录，不依赖用户预装 Python 或 Ghostscript。

## 方案选择

采用 Python 标准库 Tkinter 构建界面，使用 Ghostscript 的 `pdfwrite` 设备进行压缩，PyInstaller 打包为 Windows 可执行程序。

- Tkinter：随 Python 提供，界面小巧，足以支持单文件选择、三档单选与进度状态，不引入 Electron 的大体积运行时。
- Ghostscript：可通过 `pdfwrite` 重新生成 PDF，并可针对图片下采样，适合扫描件和图片型 PDF。官方文档说明 `/screen`、`/ebook`、`/printer` 分别对应低、中、高分辨率输出；本工具改用明确的逐项参数，避免预设中的隐式改动。
- PyInstaller：将 Python、Tkinter 和应用代码打包，Ghostscript 则作为同目录私有运行时随发行目录分发。

Ghostscript 为 AGPL/GPL 或商业许可软件。此项目按 GPL 分发 Ghostscript 运行时，并在发布目录包含其许可文件和来源说明；如果将来需要闭源商业分发，应替换为已取得商业授权的 Ghostscript。

## 用户界面

单窗口、中文界面：

- 顶部显示已选择 PDF 的文件名与“选择 PDF”按钮。
- 中部为三个等级单选项：
  - `1 级 · 清晰优先`：彩色/灰度图 200 DPI、JPEG 质量 85。
  - `2 级 · 均衡推荐`：彩色/灰度图 150 DPI、JPEG 质量 75。
  - `3 级 · 体积优先`：彩色/灰度图 110 DPI、JPEG 质量 65。
- 底部为“开始压缩”按钮、状态文本和结果区域。压缩期间禁用文件选择与开始按钮，窗口保持可响应。
- 成功时显示“打开所在文件夹”按钮；失败时显示可操作的中文原因。

## 处理流程

1. 选择文件后验证扩展名、存在性和读取权限。
2. 根据等级创建唯一输出路径；文件名冲突时在后缀前加 ` (2)`、` (3)` 等序号。
3. 在后台线程执行 `gswin64c.exe`：安全模式、批处理、无暂停、`pdfwrite` 输出，并为彩色/灰度图片设定下采样和 JPEG 参数；黑白图片保留无损压缩。
4. 捕获标准输出/错误输出和退出码。成功后验证输出文件存在、大小大于零，并用 Ghostscript 的 `nullpage` 再读取一次。
5. 回到主线程更新结果；失败时删除本次生成的不完整目标文件。

## 组件与职责

| 文件 | 职责 |
| --- | --- |
| `src/app.py` | Tkinter 窗口、用户交互、后台任务调度、结果展示。 |
| `src/compressor.py` | 等级参数、输出路径生成、Ghostscript 命令拼装、压缩与结果校验。 |
| `src/runtime.py` | 开发环境/打包环境下 Ghostscript 和资源文件路径解析。 |
| `tests/test_compressor.py` | 输出路径、命令参数、失败清理与结果校验的单元测试。 |
| `scripts/build.ps1` | 创建 Python 虚拟环境、安装依赖、下载/放置 Ghostscript 运行时、调用 PyInstaller。 |
| `scripts/verify.ps1` | 对测试 PDF 执行 1–3 级压缩并验证输出可重新读取。 |

## 错误处理与边界

- 原文件不会被覆盖；输出文件只在压缩成功后保留。
- PDF 可能已经高度优化，压缩结果可能不小于原文件；仍应保留可用输出并明确显示实际大小和比例，而不是虚报“压缩成功多少”。
- 有密码或权限限制的 PDF 直接提示“该 PDF 受密码或权限保护，暂不支持压缩”。
- 若运行时缺少 Ghostscript，提示“程序安装不完整，请重新解压完整发布目录”。
- 不处理批量文件、云端上传、在线账号、编辑 PDF 内容或覆盖原文件。

## 验证策略

1. 自动化单测覆盖三个等级的参数映射、输出文件命名冲突、非 PDF 拒绝及异常清理。
2. 使用真实的图片型 PDF，在每个等级下运行压缩；检查输出路径、新文件存在、非空、可由 Ghostscript 再读取。
3. 打包后从发布目录启动 `PDF压缩工具.exe`，使用自动化调用核心逻辑完成一次真实压缩，确认打包运行时可找到 Ghostscript。
4. 检查三档产生不同的 Ghostscript 图像下采样参数；对样本记录源/输出体积，但不将“必然变小”作为所有 PDF 的错误判定。

## 不在本次范围

- 批量压缩、拖放、多线程队列和自定义 DPI。
- PDF 解密、OCR、页面编辑、Office 转 PDF。
- 安装包签名、自动更新和商业授权。
