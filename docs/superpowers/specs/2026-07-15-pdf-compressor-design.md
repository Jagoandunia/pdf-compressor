# Windows PDF 压缩工具设计

## 目标

交付一个独立的 Windows 桌面程序。用户选择一个本地 PDF，选择压缩等级 1、2 或 3，程序生成一个新的压缩后 PDF，不改写原文件。

## 已验证的实现选择

最初评估的 Ghostscript 运行时需要 Windows 提升权限才能在本机解包，无法保证用户“下载后直接运行”的交付。因此改用 PyMuPDF 1.26.7：它提供 Windows x64 的 CPython 3.10+ 二进制包，可以由 PyInstaller 直接打进应用，无需外置程序或管理员权限。

该方案通过逐页渲染为 JPEG 并重新组装 PDF，三档参数固定为：

| 等级 | 名称 | 渲染分辨率 | JPEG 质量 |
| --- | --- | --- | --- |
| 1 | 清晰优先 | 200 DPI | 85 |
| 2 | 均衡推荐 | 150 DPI | 75 |
| 3 | 体积优先 | 110 DPI | 65 |

这对扫描件/图片型 PDF 有稳定的压缩效果。输出可阅读和打印，但所有内容会扁平化为图片：文本不能再选择或搜索，链接、表单、书签、附件和可编辑矢量内容不会保留。界面和使用说明必须明确这个取舍。

## 范围与验收标准

1. 用户可以通过文件选择器选择一个本地 PDF。
2. 用户可选择 1、2、3 三档压缩等级，默认 2 级。
3. 程序在原文件同目录生成 `<原文件名>_压缩_L<等级>.pdf`；重名时追加 ` (2)`、` (3)`。
4. 程序显示源文件体积、输出文件体积、压缩比例和输出位置。
5. 无效/损坏/受密码保护的 PDF、写入失败或输出校验失败均显示中文错误，且不保留本次不完整输出。
6. 成功输出必须非空、页数与原文件一致，并能再次用 PDF 引擎打开。
7. 最终交付为 64 位 Windows 可直接运行的 `PDF压缩工具.exe`，不要求用户安装 Python、Ghostscript 或管理员权限。

## 用户界面

单个中文窗口：

- 已选择文件名和“选择 PDF”按钮。
- 三个单选等级，默认“2 级 · 均衡推荐”。
- 明确提示“压缩后为图片 PDF，文字将不可编辑/搜索”。
- “开始压缩”按钮、工作状态、结果尺寸和“打开所在文件夹”按钮。
- 压缩在后台线程执行，窗口保持响应；处理中禁用输入。

## 组件

| 文件 | 职责 |
| --- | --- |
| `src/compressor.py` | 级别参数、输出路径、PyMuPDF 打开/渲染/重新组装、输出验证。 |
| `src/app.py` | Tkinter 窗口、文件选择、线程调度、结果和错误展示。 |
| `requirements.txt` | 运行依赖 `PyMuPDF==1.26.7`。 |
| `requirements-build.txt` | 打包依赖 `PyInstaller==6.16.0`。 |
| `scripts/build.ps1` | 建立 venv、安装依赖并生成 onedir 发布目录。 |
| `scripts/verify.ps1` | 对真实样本运行三档压缩，记录页数和体积。 |

## 处理流程

1. 验证扩展名、存在性和可读取性。
2. 用 PyMuPDF 打开输入 PDF；失败时提示文件损坏或受密码保护。
3. 对每页按所选 DPI 渲染，以所选 JPEG 质量编码，使用相同页面尺寸写入新 PDF。
4. 保存到唯一输出路径，并重新打开输出，确认非空且页数相同。
5. 任一步失败都删除本次输出；成功才显示尺寸与路径。
